# Security policy

Please do not report security vulnerabilities in public issues.

Email `harshad@indigocomputers.in` with a description, affected version, reproduction steps and potential impact. Remove passwords, WinBox databases, router exports and backups before attaching diagnostic material.

Indigo Router Scheduler stores router credentials with Windows machine-level data protection. Operators remain responsible for restricting access to the Windows management computer and securely storing exported configurations and backup manifests.
